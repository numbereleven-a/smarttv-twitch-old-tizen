# SmartTV Twitch — Old Tizen

Этот форк исправляет воспроизведение прямых трансляций Twitch на старых телевизорах Samsung Tizen. На каналах с включённым 1440p даже варианты 720p и 1080p могут передаваться в fragmented MP4 (fMP4), с которым может не справляться старый нативный плеер. Приложение использует hls.js и MediaSource. На Tizen 2.4 звук AAC и видео H.264 подаются в отдельные буферы. На Tizen 3.0 fMP4-сегменты преобразуются в MPEG-TS, после чего hls.js собирает из них MP4, который принимает телевизор.

**На проверенных каналах доступны варианты до 1080p. Воспроизведение 1440p не добавлено.**

**Проверенные устройства:**

- Samsung UE50KU6000 (серия KU6000), Tizen 2.4.0, прошивка T-JZL6DEUC-1260.1: воспроизведение подтверждено в 4.0.9. Изменения 4.1 проверены локально; этот выпуск повторно на данном ТВ не проверялся.
- Samsung UE32M5550AU (серия M5550), Tizen 3.0, семейство прошивок T-KTSDEUC: проверено воспроизведение HLS с патчем fMP4 → TS, включённым в 4.1.

## Установка

В ZIP из релиза находится WGT, из которого удалены исходные файлы подписи Samsung. Сертификат дистрибьютора Samsung привязан к DUID целевого телевизора, поэтому перед установкой скачанный WGT необходимо подписать для своего телевизора.

1. Скачайте ZIP из [последнего релиза](https://github.com/numbereleven-a/smarttv-twitch-old-tizen/releases/latest) и извлеките WGT, имя которого заканчивается на `-resign-required.wgt`.
2. Установите Tizen Studio, Samsung TV Extension и Certificate Manager.
3. Включите Developer Mode на телевизоре, подключите его к Tizen Studio и создайте профиль сертификата Samsung с DUID телевизора. Следуйте [инструкции по сертификатам](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html) и [инструкции по подключению ТВ](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
4. [Импортируйте извлечённый WGT как существующий проект Tizen](https://developer.samsung.com/smarttv/develop/getting-started/creating-tv-applications/importing-tv-applications.html).
5. Выберите свой профиль сертификата Samsung и соберите новый подписанный WGT.
6. Установите новый подписанный WGT на подключённый телевизор через Tizen Studio.

Также можно клонировать репозиторий и собрать приложение из исходников. Приложение не опубликовано в Samsung Apps.

### Обновление установленного приложения

Версия 4.1 сохраняет идентификаторы приложения версий с 4.0.5 по 4.0.10. Подпишите обновление тем же сертификатом автора и установите поверх существующего приложения, не удаляя его. Это сохраняет аккаунт и настройки; если Twitch отозвал авторизацию или она истекла, вход может потребоваться повторно. Сохраните резервную копию сертификата автора. Версия 4.0.4 остаётся отдельным приложением, её данные аккаунта не переносятся в это приложение.

## Управление плеером

- **Reload:** в панели прямого эфира нажмите вправо от Play/Pause и выберите Reload. Кнопка заново загружает текущий канал, сохраняя выбранное качество. Reload также доступен в окне ошибки воспроизведения прямого эфира.
- **Задержка эфира:** при воспроизведении через HLS панель показывает примерное отставание, например `LIVE · ~8 s`. Это расстояние до доступного края HLS-потока, а не полная задержка от камеры до телевизора. В Native и при отсутствии оценки значение не отображается. Reload запускает новую сессию ближе к прямому эфиру, но не устраняет задержку доставки Twitch.
- **Автоматический повтор запуска:** ошибка прямого эфира до начала воспроизведения вызывает один автоматический Reload. Повторная ошибка показывает обычное окно. Ошибки остаются в истории debug до закрытия приложения; уже начавшийся просмотр автоматически не перезапускается.
- **To live:** нажмите вправо дважды от Play/Pause. Кнопка доступна только для HLS live, включая Auto с выбранным HLS. Она обновляет плейлист и перемещает позицию ближе к live без перезапуска канала.
- **Пауза HLS live:** останавливает видео и загрузку потока, чтобы кадр оставался неподвижным. Play возобновляет загрузку с прежней позиции; если она вышла из доступного окна потока, hls.js может вернуть воспроизведение к live.
- **Статус загрузки:** рядом с индикатором показывается текущий этап, включая проверку формата, запуск Native, переход на HLS и автоматический повтор.
- **Активный плеер:** панель показывает HLS, Native или Video. В режиме Auto отображается выбранный плеер, например `Auto · HLS`.
- **Playback debug log:** включите этот пункт в настройках плеера для отображения версии приложения, модели ТВ, версии Tizen, состояния плеера, буфера и последних ошибок. По умолчанию окно выключено. Последние пять ошибок хранятся в памяти даже при выключенном окне: дата и время по часам ТВ, этап, код и текст исключения, если он доступен. История остаётся после Reload, но очищается при закрытии приложения. Адреса потоков и токены авторизации скрываются. Файл с ошибками не создаётся.

Для прямого эфира доступны три режима:

- **HLS:** hls.js/MSE для всех каналов на ТВ с поддержкой MSE.
- **Auto (по умолчанию для новых установок):** проверяет плейлист выбранного качества, выбирает HLS для потоков с картой инициализации (включая Twitch fMP4), а обычные потоки запускает через Samsung AVPlay. Если Native выдаёт ошибку или не завершает подготовку за настроенное время ожидания запуска Native (по умолчанию 15 секунд), Auto переключается на HLS при доступном MSE.
- **Native start timeout (seconds):** в настройках плеера можно выбрать 10, 15, 20 или 30 секунд. Значение применяется к следующему запуску Native и не меняет задержку LIVE.
- **Native:** принудительно использует Samsung AVPlay и не переключается скрытно на HLS. Для неподдерживаемого потока показывает ошибку с предложением выбрать HLS или Auto.

Прежняя настройка Native с автоматическим переходом при обновлении становится Auto. Выбранный ранее HLS остаётся HLS.

## Требования и совместимость

Подтверждённые конфигурации перечислены выше. Приложению необходимы среда веб-приложений Samsung Tizen с работающим MediaSource (MSE), отдельными MP4 SourceBuffer для H.264/AVC и AAC, аппаратное декодирование выбранного варианта и сеть с доступом к API и CDN Twitch. Проверенные прямые трансляции использовали H.264 и AAC. Телевизор должен принимать WGT, подписанный для его DUID.

Новый загрузчик fMP4 → TS включается только на Tizen 3 и новее. На Tizen 2.4 сохраняются исходный загрузчик hls.js и прежнее разделение буферов fMP4. Локальные проверки охватывают оба режима задержки и преобразование сегментов, но не заменяют тест на физическом Tizen 2.4. Исправление для Tizen 3 пропускает части LL-HLS: для них сохраняется исходный путь fMP4.

Приложение запоминает последнее качество прямого эфира, явно выбранное пользователем. При первом запуске начальное предпочтение — 720p.

Минимум Tizen 2.3 в манифесте — требование к установке, но не подтверждение работы на всех телевизорах с Tizen 2.3. Другие модели, чипсеты, прошивки, кодеки, длительность просмотра и разрешения отдельно не проверялись. Положительный результат `MediaSource.isTypeSupported()` сам по себе не гарантирует воспроизведение.

Обработка рассчитана на структуру Twitch fMP4, проверенную при разработке. Это не универсальный MP4-конвертер. Поддержка шифрованных потоков и вывода 1440p не заявляется.

## Сборка

Нужен проект веб-приложения Tizen, Tizen Studio с Samsung TV Extension и профиль сертификата Samsung:

```text
tizen build-web -- app
tizen package -t wgt -s YOUR_CERTIFICATE_PROFILE -- app/.buildResult
```

Для установки включите Developer Mode на телевизоре, подключите его к Tizen Studio, разрешите установку и установите WGT. См. [инструкцию Samsung по настройке ТВ](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
